# Scripts

Python helpers for the curated data pipeline and the offline site build.

Run every command from the repository root. Subfolder scripts bootstrap
`sys.path` so they can import the shared [`data_model.py`](data_model.py) module;
the stable entry point stays [`build_all.py`](build_all.py).

## Entry point

```bash
python scripts/build_all.py          # validate, rebuild and check the site
python scripts/build_all.py --check  # fail if a rebuild changes a generated byte
```

`build_all.py` runs the pipeline steps in order:

1. [`pipeline/validate.py`](pipeline/validate.py)
2. [`pipeline/build_psn_ledger.py`](pipeline/build_psn_ledger.py)
3. [`pipeline/build_projects.py`](pipeline/build_projects.py)
4. [`pipeline/build_dictionary.py`](pipeline/build_dictionary.py)
5. [`pipeline/freshness.py`](pipeline/freshness.py)
6. [`pipeline/audit_claims.py`](pipeline/audit_claims.py)
7. [`pipeline/build_site_data.py`](pipeline/build_site_data.py)
8. [`pipeline/build_factories_ledger.py`](pipeline/build_factories_ledger.py)
9. [`pipeline/check_site.py`](pipeline/check_site.py)

## Layout

| Folder | Purpose |
|---|---|
| [`pipeline/`](pipeline/) | Deterministic build steps. Run these through `build_all.py` unless debugging one stage. |
| [`imports/`](imports/) | Batch import and extraction tools. Run only when the underlying source changes; most are idempotent. |
| [`tools/`](tools/) | Optional geocoding, schema migration and claim normalisation. |
| [`dev/`](dev/) | Development-only checks that are not part of the build. |

## Pipeline

| Script | Purpose |
|---|---|
| [`pipeline/validate.py`](pipeline/validate.py) | Schema, enums, dates, coordinates, foreign keys, events, geometry, atomic claims, conflicts and coverage checks. |
| [`pipeline/build_projects.py`](pipeline/build_projects.py) | Joins operators and sources, fills gaps from the BPJT snapshot and writes `data/exports/projects.csv`. |
| [`pipeline/build_dictionary.py`](pipeline/build_dictionary.py) | Writes `data/derived/data_dictionary.csv` and `site/downloads/dictionary.csv`. |
| [`pipeline/freshness.py`](pipeline/freshness.py) | Writes the row-level freshness report. |
| [`pipeline/audit_claims.py`](pipeline/audit_claims.py) | Writes the per-project claim coverage audit. |
| [`pipeline/build_site_data.py`](pipeline/build_site_data.py) | Writes runtime JS to `site/data/` and downloads to `site/downloads/`. |
| [`pipeline/build_factories_ledger.py`](pipeline/build_factories_ledger.py) | Writes the frozen 34-plant factory ledger. |
| [`pipeline/check_site.py`](pipeline/check_site.py) | Checks payload counts, IDs, search coverage, downloads and local-only assets. |

| [`imports/build_transport.py`](imports/build_transport.py) | Imports the 35 transport rows into the curated tables. |
| [`imports/add_bpjt_psn_roads.py`](imports/add_bpjt_psn_roads.py) | Adds the 15 missing PSN toll corridors. |
| [`imports/add_factories.py`](imports/add_factories.py) | Adds the 27 factory rows, organisations, claims and investments. |
| [`imports/add_flagships.py`](imports/add_flagships.py) | Adds the 24 flagship rows, sources, organisations, claims, investments and events. |

## Tools

| Script | Purpose |
|---|---|
| [`tools/geocode_estates.py`](tools/geocode_estates.py) | Improves coordinates for the largest industrial estates with Nominatim. |
